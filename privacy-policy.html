LiteCopy Privacy Policy

All free features work entirely offline — zero network requests. The only network communication is optional Premium license verification: entering a key sends a minimal install identifier and the key to the license server. Premium site rules sync through your own browser account (chrome.storage.sync) and never reach the developer's servers. If you never activate a license, the extension never connects to the internet.

01Data Collection

LiteCopy does not collect any personal information, browsing data, or usage analytics. We do not use cookies, tracking, or telemetry of any kind.

02How It Works

  • Toggle — Click the extension icon to inject/remove CSS and JS that restore text selection
  • Processing — All modifications happen locally in your browser tab
  • Offline First — Free features work entirely offline with zero network requests
  • Premium Site-Rule Sync — With an active license the site list is mirrored to chrome.storage.sync, your browser's own account sync. The developer has no server for it and cannot read it. Sync stops if the license is removed; local rules keep working
  • Remembered Sites — Enabling LiteCopy on a site stores that domain in chrome.storage.local, so return visits auto-enable. The developer never receives this list, and turning LiteCopy off for a site removes the entry from this device and from the synced list

03Permissions

LiteCopy requests activeTab, scripting and storage to inject the unlock script when you turn it on and to keep license status, site rules and remembered sites on your device. Site access is required so that sites you have enabled can be re-unlocked automatically on your next visit; no page content is ever read or transmitted. Premium site-rule sync uses chrome.storage.sync under the same storage permission.

04Third-Party Services

License Verification (Premium): If you activate a premium license, LiteCopy contacts our license server at api.annmax1983.com directly; Creem only handles the payment. The request includes: license key, a random install identifier, plugin identifier, and browser metadata. If you never activate a license, the extension makes zero network requests. Our license server records the IP address of these requests solely for rate limiting and abuse prevention — never for profiling, advertising, or sharing with third parties.

05Data Sharing

We do not share, sell, rent, or trade any data with third parties because we do not collect any data.

06Data retention & deletion

Your settings and content stay in your browser until you delete them in the extension or uninstall it. Uninstalling removes the extension's local data. Nothing is retained on our servers, because your content is never sent to them. If you enabled a feature that uses your browser account's sync, a copy may remain in that account. You can manage or remove it in your browser's sync settings.

07Changes to this policy

If this policy changes, the revised version will be published on this page with a new date. Material changes will be noted in the extension's release notes.

08Contact

Questions about this policy? Email support@annmax1983.com or open an issue on GitHub.
