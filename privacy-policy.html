Privacy Policy

LiteCopy · Last updated: July 2026

TL;DR: All free features work entirely offline — zero network requests. The only network communication is optional Premium license activation: when you enter a license key, a minimal device identifier is sent to the license server for verification. If you never activate a license, the extension never connects to the internet.

1. Data Collection

LiteCopy does not collect any personal information, browsing data, or usage analytics. We do not use cookies, tracking, or telemetry of any kind.

2. How It Works

  • Toggle — Click the extension icon to inject/remove CSS and JS that restore text selection
  • Processing — All modifications happen locally in your browser tab
  • Offline First — Free features work entirely offline with zero network requests
  • Usage Counter — A daily copy counter is stored locally using chrome.storage.local
  • Remembered Sites — Enabling LiteCopy on a site stores that domain locally with chrome.storage.local, so return visits auto-enable. This list never leaves your browser and the entry is removed when you turn LiteCopy off for that site

3. Permissions

LiteCopy requests activeTab, scripting and storage to inject the unlock script when you turn it on and to keep your daily counter, license status and remembered sites on your device. Site access is required so that sites you have enabled can be re-unlocked automatically on your next visit; no page content is ever read or transmitted.

4. Third-Party Services

License Verification (Premium): If you activate a premium license, LiteCopy connects to a license verification server at api.annmax1983.com to validate your key via Creem (payment processor). The request includes: license key, device fingerprint ID, plugin identifier, and browser metadata (version, language, timezone). Creem processes this data per their privacy policy. If you never activate a license, the extension makes zero network requests.

5. Data Sharing

We do not share, sell, rent, or trade any data with third parties because we do not collect any data.

6. Changes

If we make changes to this policy, we will update the "Last updated" date above.

7. Contact

Questions? Open an issue on our GitHub.
