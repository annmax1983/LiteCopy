## なぜ LiteCopy？

ウェブサイトからテキストをコピーしようとして、選択できなかったり、右クリックがブロックされたり、Ctrl+Cが効かなかったことはありませんか？LiteCopy はワンクリックで全て解決します。

| 利点 | 詳細 |
|------|------|
| 🔓 **ワンクリックで復元** | テキスト選択を瞬時に復元、ページ更新不要 |
| 🔒 **最小権限** | `activeTab` + `scripting` + `storage` |
| ⚡ **軽量** | フレームワークなし、実行時依存なし |
| 🌍 **6言語** | 英語、中国語、スペイン語、ドイツ語、日本語、フランス語 |
| 🚫 **ゼロトラッキング** | 分析なし、テレメトリなし。無料版はデータを送信しません。プレミアム認証時のみデバイスIDとキーを api.annmax1983.com に送信して検証します |

## インストール

1. ブラウザの拡張機能ページを開く
2. **デベロッパーモード**を有効にする
3. **パッケージ化されていない拡張機能を読み込む**をクリックし、`lite-copy` フォルダを選択

---

## 使い方

1. コピー制限のあるウェブサイトにアクセス
2. **LiteCopy** アイコンをクリック — ポップアップが開きます
3. **有効化**をクリック — テキスト選択が瞬時に復元
4. 無効化するには、再度ポップアップを開いて**無効化**をクリック（ページが再読み込み）

> **注意:** ブラウザー制限ページ（`chrome://`、Chrome ウェブストアなど）は変更できません。ポップアップにエラーが表示され、アンロックは消費されません。
