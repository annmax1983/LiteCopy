# LiteCopy

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

任意のWebサイトで、ネイティブのテキスト選択、右クリックメニュー、コピーショートカットを復元する軽量ブラウザ拡張機能です。

> Chromium系ブラウザ対応 · Manifest V3 · 最小限の権限 · 無料＋Premium

---

## LiteCopyの特長

Webサイトからテキストをコピーしようとして、選択できなかったり、右クリックがブロックされたり、Ctrl+Cが効かなかった経験はありませんか？LiteCopyはワンクリックでこれらすべてを解決します。

| 特長 | 詳細 |
|-----------|--------|
| 🔓 **ワンクリック有効化** | ネイティブのテキスト選択を瞬時に復元 — ページ再読み込み不要 |
| 🔒 **最小限の権限** | `activeTab`＋`scripting`＋`storage` — 機能に必要な権限のみ |
| ⚡ **軽量** | フレームワーク不使用、ランタイム依存なし |
| 🌍 **6言語対応** | 英語、中国語、スペイン語、ドイツ語、日本語、フランス語 |
| 🚫 **トラッキングなし** | アナリティクス、テレメトリなし。無料版ではデータ送信ゼロ。Premium有効化時はデバイスID＋キーをapi.annmax1983.comに送信して検証 |
| 🎯 **シンプルなトグル** | ポップアップを開いてEnable/Disable — ON/OFF状態が明確に表示 |

## インストール

1. ブラウザの拡張機能ページを開きます：
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
2. **デベロッパーモード**を有効にします（右上のトグル）
3. **パッケージ化されていない拡張機能を読み込む**をクリックし、`lite-copy`フォルダを選択します
4. ツールバーにLiteCopyアイコンが表示されます

---

## 使い方

1. コピーやテキスト選択がブロックされているWebサイトにアクセスします
2. ツールバーの**LiteCopy**アイコンをクリック — ポップアップが開きます
3. **Enable**をクリック — テキスト選択が即座に復元されます
4. 無効化するには、ポップアップを再度開いて**Disable**をクリックします（元の動作を復元するためにページが再読み込みされます）

> **注：** ブラウザ制限ページ（`chrome://`、Chrome Web Storeなど）は変更できません。ポップアップにエラーが表示されます。

**ページ情報コピー：**
- アイコンをクリック → ポップアップが開く
- ボタンでページタイトル、URL、または両方をコピー

**使用状況の確認：**
- 上部の使用状況バーに1日のコピー回数が表示されます
- 無料ユーザー：1日100回コピー、深夜にリセット
- Premiumユーザー：⭐ 無制限

## プライバシー

- ✅ **アナリティクスなし** — トラッキング、テレメトリなし
- ✅ **無料版：ネットワークリクエストゼロ** — すべての処理はローカルで実行。Premiumを有効化しない限りデータは送信されません
- ✅ **最小限の権限** — `activeTab`＋`scripting`＋`storage`、およびライセンスAPIホスト
- ✅ **サイト記憶なし** — ブラックリスト/ホワイトリスト、サイト設定の保存なし
- ✅ **ライセンス検証のみ** — Premiumライセンスを有効化した場合、最小限のデバイスIDとライセンスキーが`api.annmax1983.com`に送信されて検証されます。ライセンスを有効化しない場合、データは送信されません。
