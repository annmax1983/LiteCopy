# LiteCopy

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

任意のWebサイトで、ネイティブのテキスト選択、右クリックメニュー、コピーショートカットを復元する軽量ブラウザ拡張機能です。

> Chrome / Edge / Firefox · Manifest V3 · 無料でコピー無制限 · Proはサイトルールを端末間同期

---

## LiteCopyの特長

Webサイトからテキストをコピーしようとして、選択できなかったり、右クリックがブロックされたり、Ctrl+Cが効かなかった経験はありませんか？LiteCopyはワンクリックでこれらすべてを解決します。

| 特長 | 詳細 |
|-----------|--------|
| 🔓 **ワンクリック有効化** | ネイティブのテキスト選択を瞬時に復元 — ページ再読み込み不要 |
| ♾️ **無料で無制限** | コピー・選択・右クリックを好きなだけ — 1日の上限も回数カウンターもなし |
| 🔄 **サイトルールを端末間で同期** | Proでは、有効化したサイトをブラウザ標準のアカウント同期（Chrome同期 / Edge同期 / Firefox同期）で共有 |
| 🔒 **ローカル設計** | 解除は`activeTab`＋`scripting`でローカル実行。サイトアクセス権限は有効化したページにのみ使用 |
| ⚡ **軽量** | フレームワーク不使用、ランタイム依存なし |
| 🌍 **6言語対応** | 英語、中国語、スペイン語、ドイツ語、日本語、フランス語 |
| 🚫 **トラッキングなし** | アナリティクス、テレメトリなし。閲覧履歴やサイトリストを保存する開発者サーバーはありません |
| 🎯 **シンプルなトグル** | ポップアップを開いてEnable/Disable — ON/OFF状態が明確に表示 |

## 機能一覧

### 🆓 無料版 — 無制限

| 機能 | 説明 |
|---------|-------------|
| 🔓 **テキスト選択の復元** | 無効化されているサイトでデフォルトのテキスト選択を復元 |
| 🖱️ **右クリックメニューの復元** | 制限されたサイトでブラウザの右クリックメニューを回復 |
| ⌨️ **キーボードショートカットの復元** | Ctrl+C、Ctrl+V、Ctrl+Aなどの標準ショートカットを回復 |
| 🛡️ **オーバーレイ干渉の修正** | テキスト選択を妨げる透明オーバーレイdivを修正 |
| 🔄 **トグルON/OFF** | ポップアップからEnable/Disable、無効化時にページが再読み込み |
| 🧠 **サイトの記憶** | 有効化したサイトをローカルに記憶し、次回訪問時に自動で有効化 |
| 💬 **トースト通知** | 自動消去の通知で有効化ステータスを表示 |
| 📋 **ページ情報コピー** | ポップアップのボタンでページタイトル、URL、または両方をコピー |
| 🖱️ **右クリックメニュー** | メニューのチェックで、表示中のサイトが解除済みかどうかがわかります。同じメニューからタイトルと URL のコピーやサイト管理も開けます |
| 🗂 **サイト管理** | 記憶したすべてのドメインを、この端末がアクセスを許可済みかどうかとフル / ライトモードの一覧で表示する独立ページ。各行は確認をもう一度挟んで削除できます |
| 🪶 **サイト別のライトモード** | スライダー型CAPTCHAやリッチテキストエディタを使うサイトで、右クリックと選択のみを復元 — LiteCopyはコピーやキーボードイベントにはまったく干渉しません |

> 上記の機能はすべて無料・無制限です。1日の割り当てやリセットはありません。

### ⭐ Pro — サイトルールを端末間で同期

| 機能 | 説明 |
|---------|-------------|
| 🔄 **サイトルールの端末間同期** | 一度サイトを有効化すれば、ルールがブラウザアカウントに追従し、同じアカウントでサインインした他の端末でも自動的に有効になります |
| 🔐 **ブラウザアカウントで同期** | リストはブラウザが`storage.sync`に保存します。LiteCopyアカウントは不要で、開発者サーバーにリストは保存されず、開発者もアクセスできません |
| 💻 **端末ごとのアクセス許可** | ブラウザのサイトアクセス権限は同期できません。新しい端末では、同期済みのサイトで一度「有効にする」を押してアクセスを許可してください。ルール自体はすでに保存されています |
| 🧭 **手動同期** | 設定の**今すぐ同期**ボタンで、いつでもブラウザアカウントから最新リストを取得できます |
| 📦 **ルールのバックアップと移行** | 記憶したすべてのサイト（フル/ライトモード込み）をJSONファイルにエクスポートし、別のブラウザプロファイルや端末でインポートできます |

## 使い方

1. コピーやテキスト選択がブロックされているWebサイトにアクセスします
2. ツールバーの**LiteCopy**アイコンをクリック — ポップアップが開きます
3. **Enable**をクリック — テキスト選択が即座に復元されます
4. 無効化するには、ポップアップを再度開いて**Disable**をクリックします（元の動作を復元するためにページが再読み込みされます）

> **注：** ブラウザ制限ページ（`chrome://`、Chrome Web Store、Microsoft Edgeアドオン、Firefoxアドオン（AMO）など）は変更できません。ポップアップにエラーが表示されます。

**右クリックメニュー：**
- 右クリックメニューの**このサイトで有効化**はチェック項目です。表示中のサイトが解除済みならチェックが入っています。チェックで有効化、チェックを外すとサイト全体を無効化します（ルールが削除され、ページが再読み込みされます）
- **ページのタイトルとURLをコピー**と**サイトを管理**も同じメニューにあります
- メニューから有効化するとサイトのアクセス許可を一度だけ求められます。拒否しても、現在のタブはその閲覧中は解除されます

**サイト管理：**
- ポップアップの**サイトを管理**ボタン、または右クリックメニューから開きます
- 記憶したすべてのドメインが一覧され、この端末がアクセスを許可済みかどうか、**フル / ライト**の切り替え、削除をもう一度クリックして確定する**削除**ボタンが表示されます
- サイトを記憶した後は、**フル / ライト**をポップアップから直接切り替えられます。開いているタブには再読み込みなしで反映されます
- **ライト**は右クリックとテキスト選択のみを復元します。コピーやキーボードのイベントには触れないため、スライダー型CAPTCHAやリッチテキストエディタが通常どおり動作します

**サイトルールと同期（Pro）：**
- ある端末でサイトを有効化すると、ルールがブラウザアカウントの同期ストレージに追加されます
- 同じブラウザアカウントでサインインした別の端末では、そのサイトが保存済みルールとして表示されます。一度**有効にする**を押して、その端末のサイトアクセスを許可してください
- **設定**で同期済みサイト数を確認でき、すぐに更新したいときは**今すぐ同期**を使います
- **エクスポート / インポート**はポップアップではなく、サイト管理の**バックアップと移行**カードにあります。サイトリスト（ライトモードの設定も含む）をJSONファイルに保存し、別のプロファイルで復元できます。フル/ライトの選択は端末ごとに保存され、自動的に同期されるのはドメインリストのみです

**ページ情報コピー：**
- アイコンをクリック → ポップアップが開く
- ボタンでページタイトル、URL、または両方をコピー

## プライバシー

- ✅ **アナリティクスなし** — トラッキング、テレメトリなし
- ✅ **無料機能：ネットワークリクエストゼロ** — すべての処理はローカルで実行。Proを有効化しない限りデータは送信されません
- ✅ **必要最小限の権限** — `activeTab`＋`scripting`＋`storage`で解除を実行し、`contextMenus`はブラウザ本来の右クリックメニューに項目を追加するだけ、`alarms`はProライセンスの定期再検証にのみ使用、サイトアクセス権限は有効化したページへの注入にのみ使用、さらにライセンスAPIホスト
- ✅ **サイトリストは既定でローカルのみ** — サイトでLiteCopyを有効化すると、そのドメインが`storage.local`に保存されます。このリストが開発者に送信されることはありません
- ✅ **Proの同期はブラウザアカウントを使用** — ライセンスが有効な間、リストは`storage.sync`（ブラウザベンダーのアカウント同期）にも保存されます。開発者はアクセスできず、コピーも受け取りません。ライセンスを削除すると同期は停止し、ローカルルールは引き続き機能します
- ✅ **ライセンス検証のみ** — Proライセンスを有効化すると、ライセンスキー、ランダムなインストール識別子、プラグイン識別子、ブラウザメタデータ（ブラウザ、言語リスト、タイムゾーン、ユーザーエージェント）が検証のために`api.annmax1983.com`に送信されます。プライバシーポリシーに記載と同じ項目です。ライセンスを有効化しない場合、データは送信されません
