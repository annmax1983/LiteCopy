## 安装方法

1. 打开浏览器扩展页面：
   - **Chrome**：`chrome://extensions/`
   - **Edge**：`edge://extensions/`
2. 开启右上角的**开发者模式**
3. 点击**加载已解压的扩展程序**，选择 `lite-copy` 文件夹
4. 工具栏中出现 LiteCopy 图标

---

## 使用方法

1. 访问任何限制复制或选中的网页
2. 点击工具栏中的 **LiteCopy** 图标，弹出 Popup
3. 点击**启用**，文本选中功能瞬间恢复
4. 需要关闭时，再次打开 Popup 点击**禁用**（页面自动刷新恢复原状）

> **注意：** 浏览器受限页面（`chrome://`、Chrome 应用商店等）无法修改。Popup 会提示错误，且不会消耗解锁次数。

**复制页面信息：**
- 点击图标 → 打开 Popup
- 使用按钮复制页面标题、链接或两者
