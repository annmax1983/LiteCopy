遇到过网页不让复制、不让选中文字、右键被拦截的情况吗？LiteCopy 一键搞定。

| 优势 | 说明 |
|------|------|
| 🔓 **一键启用** | 瞬间恢复文本选中功能，无需刷新页面 |
| ♾️ **免费不限次** | 复制、选中、右键想用多少次就用多少次，没有每日上限，也没有次数计数器 |
| 🔄 **跨设备站点规则** | 高级版通过浏览器自带的账户同步（Chrome 同步 / Edge 同步）让你的站点规则跟随账户 |
| 🔒 **本地处理** | `activeTab` + `scripting` 在本地完成解锁；站点访问权限仅用于在您启用的页面注入 |
| ⚡ **极简轻量** | 无框架、无运行时依赖 |
| 🌍 **6 种语言** | 英文、中文、西班牙文、德文、日文、法文 |

## 功能特性

### 🆓 免费版 — 无限使用

| 功能 | 说明 |
|------|------|
| 🔓 **恢复文本选中样式** | 覆盖 `user-select:none` 和 `-webkit-user-select:none` |
| 🖱️ **恢复右键菜单** | 恢复被拦截的右键菜单 |
| ⌨️ **恢复复制粘贴快捷键** | 恢复 Ctrl+C、Ctrl+V、Ctrl+A 等复制粘贴快捷键 |
| 🛡️ **清除遮罩层** | 禁用阻止文本选中的透明覆盖层 |
| 🔄 **开关切换** | 弹窗内启用/禁用，禁用时自动刷新页面 |
| 🧠 **记住站点** | 已启用的站点会保存在本地，下次访问自动启用 |
| 💬 **轻提示** | 自动消失的提示，告知激活状态 |
| 📋 **复制页面信息** | Popup 按钮：复制页面标题、链接或两者 |

> 以上功能全部免费且不限次数，没有每日配额，也不会重置计数。

### ⭐ 高级版 — 站点规则跨设备同步

| 功能 | 说明 |
|------|------|
| 🔄 **跨设备站点规则** | 在一个设备上启用某站点后，规则会跟随浏览器账户，在登录同一账户的其他设备上自动启用 |
| 🔐 **浏览器账户同步** | 站点列表由浏览器保存在 `storage.sync` 中。无需 LiteCopy 账户，不经过开发者服务器，开发者也读不到 |
| 💻 **每台设备单独授权** | 浏览器的站点访问权限无法同步。在新设备上只需对已同步的站点点一次「开启」完成授权，规则本身已经存在 |
| 🧭 **手动同步** | 设置中的「立即同步」按钮可随时从浏览器账户拉取最新列表 |

> 💡 一次性购买或月度订阅。[获取许可证 →](https://www.annmax1983.com/checkout.html?plugin=litecopy)

## 使用方法

1. 访问任何限制复制或选中的网页
2. 点击工具栏中的 **LiteCopy** 图标，弹出 Popup
3. 点击**启用**，文本选中功能瞬间恢复
4. 需要关闭时，再次打开 Popup 点击**禁用**（页面自动刷新恢复原状）

> **注意：** 浏览器受限页面（`chrome://`、Chrome 应用商店等）无法修改。Popup 会提示错误。

**站点规则与同步（高级版）：**
- 在设备 A 上启用某站点后，规则会写入浏览器账户的同步存储
- 在登录同一浏览器账户的设备 B 上，该站点会显示为已保存规则；点一次**开启**完成本设备的访问授权即可
- 打开**设置**可查看已同步站点数量，需要立即刷新时点击**立即同步**

**复制页面信息：**
- 点击图标 → 打开 Popup
- 使用按钮复制页面标题、链接或两者

## 隐私

- ✅ **无分析** — 无追踪、无遥测
- ✅ **免费功能零网络请求** — 所有处理在本地完成；未激活高级版时不发送任何数据
- ✅ **精简权限** — `activeTab` + `scripting` + `storage` 用于执行解锁，站点访问权限仅用于在您启用的页面注入，另加许可证 API 域名
- ✅ **站点列表默认只存本地** — 在某个网站启用 LiteCopy 后，该域名会记录在本地 `storage.local` 中。此列表不会发送给开发者
- ✅ **高级版同步使用浏览器账户** — 许可证有效期间，站点列表还会镜像到 `storage.sync`，即浏览器厂商提供的账户同步。开发者无权访问，也收不到副本。移除许可证后同步停止，本地规则继续有效
- ✅ **仅许可证验证** — 激活高级版时，仅向 `api.annmax1983.com` 发送随机安装标识和许可证密钥进行验证；不激活则不发送任何数据
